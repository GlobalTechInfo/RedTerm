# Security Policy

## Supported versions

Only the latest release is supported with security updates.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue for
anything you believe is a security problem.

Preferred: use GitHub's private vulnerability reporting

- https://github.com/GlobalTechInfo/RedTerm/security/advisories/new

What to include:

- The RedTerm version (or commit) you are using
- The affected component (terminal, proot launcher, storage handling, etc.)
- A description of the issue and, if possible, steps to reproduce
- Impact you observed and any suggested fix

## What happens next

- You will get an acknowledgement within 7 days.
- We will confirm or dismiss the report and keep you informed.
- A fix is released as soon as possible; public disclosure happens after
  the fix is available.
